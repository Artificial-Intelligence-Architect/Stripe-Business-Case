### Assumptions

- Transaction volume: $1.2T/year (Stripe public figure + 10% growth)
- Baseline fraud rate without ML: 0.15% (industry average)
- Model detection rate: 92% (validated on holdout data)
- False positive rate: 2% (real‑time fraud threshold)
- FP investigation cost: $5 per transaction
