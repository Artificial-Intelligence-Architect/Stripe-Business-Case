# Grafana Dashboards

Dashboard templates for Prometheus metrics.

## Available Dashboards
1. Executive Overview (C-level KPIs)
2. OLTP Deep Dive (TPS, latency, cache, replication)
3. OLAP Deep Dive (warehouse, credits, spill)
4. ML Model Health (inference, AUC, drift)
5. Kafka & Streaming (consumer lag, throughput)

See docs/09_observability.md for full dashboard configuration.
